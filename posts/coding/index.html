🧪 Advanced Logic: The Armstrong Number Beginner ⏱️ 5-10 mins

An Armstrong Number (also called a Narcissistic Number) is a number that equals the sum of its digits raised to the power of the number of digits.

Example: 153 is an Armstrong number because 1³ + 5³ + 3³ = 1 + 125 + 27 = 153

Approach:

  1. Count the total number of digits in the number
  2. Extract each digit using modulo operator (%)
  3. Raise each digit to the power of digit count
  4. Sum all the powered digits
  5. Compare the sum with original number
# Armstrong Number Checker
def is_armstrong(n):
    digits = 0
    temp = n
    
    # Count digits
    while temp > 0:
        digits += 1
        temp //= 10
    
    # Check if Armstrong
    sum_powers = 0
    temp = n
    while temp > 0:
        digit = temp % 10
        sum_powers += digit ** digits
        temp //= 10
    
    return sum_powers == n

# Test cases
test_nums = [153, 370, 9474, 100]
for num in test_nums:
    result = "Armstrong" if is_armstrong(num) else "Not Armstrong"
    print(f"{num}: {result}")
✅ Output: 153: Armstrong | 370: Armstrong | 9474: Armstrong | 100: Not Armstrong

💡 Tips for Coding Newbies

  • Indentation is Key: In Python, a missing space can break your whole program - always use consistent spacing
  • Dry Run: Before running code, trace variable values (like sum or temp) on paper to debug logic
  • Use range() wisely: Remember that range(1, 6) goes from 1 to 5, not 6!
  • Practice Daily: Consistency beats intensity - solve at least one problem every day
  • Read Error Messages: Python errors tell you exactly what went wrong - don't ignore them!
  • Test Edge Cases: Always test with 0, 1, negative numbers, and large numbers
